# PR1 actual browser evidence

These are actual Playwright Chromium recordings against deterministic synthetic Firebase Auth/Firestore emulators, recorded 2026-11-12. They contain no production data, live Google consent, or real-device/mobile claims. The primary videos are paced at one-quarter speed (timestamps scaled 4x) for review: signup/reuse is 25.48 seconds and team/display is 21.64 seconds. Stream-copy retiming preserves every original encoded frame and step; no new frames or fabricated interactions are added. Fast originals remain in the successful Playwright test-results/CI artifact.

- [Sign in once and reuse registration](https://github.com/user-attachments/assets/4201f849-4d34-446a-be3b-762021f8be4b): delivered-emulator email verification, destination retained, minimal profile, first event, rejoin, prefilled second event, another member's profile, own name edit, social-profile deletion. The separate fresh-browser login runs while the first context stays open.
- [Fresh device context](https://github.com/user-attachments/assets/fe19d3dc-5164-4126-a5d8-cf404e7bee23): independent empty browser storage signs into the same permanent account and resumes its existing event registration, with no second participant record.
- [Workshop regression](https://github.com/user-attachments/assets/8ffb6d61-0f55-4e4c-8b0b-05eacd710afe): event-code join, actual challenge selection, actual team formation/finalization/naming writes, existing projector screen, and social-profile deletion retaining organizer access.

All recording links above open the verified GitHub video attachments published in the PR description. CI also uploads successful videos in `pr1-emulator-browser-evidence` for 14 days. The fourth browser journey (single/bulk publishing and attribution deletion) is included in CI recordings.

Reproduce: `npm ci`, `npx playwright install chromium`, `npm run typecheck`, `npm run build`, `npm run test:emulators`, then `node scripts/collect-demo.mjs`. The collection script refuses a failed browser run, locates Playwright's bundled ffmpeg (or FFMPEG_PATH), and stream-copies the original recordings with 4x timestamps without starting app/emulators. Local result: **15 emulator authorization/integrity tests and four Chromium browser journeys passed**. Test source and fixture details: [identity-pr1.md](../identity-pr1.md).
